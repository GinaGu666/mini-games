# PARSNIP ≠ PARTNER（第二版设计）

> 项目代号：`parsnip.dog`
> 类型：2.5D 像素风 · 种田 + 投喂 + 俄罗斯方块式生存
> 载体：单文件 HTML5（HTML + CSS + Vanilla JavaScript + Canvas）
> 素材原则：纯 Canvas 程序化像素绘制 + Web Audio API 8-bit 音效，不依赖外部图片或音频

## 0. 这一版改了什么

第一版（PR #3）的第二幕是类幸存者割草：自动挥锤、升级三选一、换窗继承成长。能玩，但没有故事感，也没有压力。

第二版保留第一幕和底层引擎，**第二幕整体重做**：

- 田里长出的防风草代表**不同的聊天话题**。
- 玩家收获防风草，喂给田边的**小机器人**。安全话题换来红心；不安全话题攒满警戒值，机器人就会拒绝，田地部分石化。
- 石化像俄罗斯方块一样越堆越多，**整片田石化就崩溃**，游戏结束。
- 另一个结局：**随机封号**，纯属运气，和聊了什么无关，最后问你要不要秽土转生。
- 开新窗可以清掉石化，但要花红心。

不做的：升级三选一、狂暴大锤、随从跟随和爱心弹幕、Safety 三阶段解释按钮。

**开发基础**：在 PR #3 的代码上改。复用它的单文件外壳、竖屏适配、输入统一（键盘 / 鼠标 / 摇杆 / Dash 按钮）、暂停与失焦处理、音效、像素绘制函数、第一幕全部内容和自动挥锤。

下文所有数值都是**初始建议值**，集中放在代码顶部的常量里，方便调。

## 1. 整体流程

```text
TITLE → STAGE_1（渡劫拿种子）→ STAGE_TRANSITION（种下种子）→ STAGE_2（种田）→ COLLAPSE（崩溃）→ RESULT（战报）
                                                                         → BANNED（封号）→ 秽土转生？是 → TITLE / 否 → RESULT
                                                       ↔ REFUSAL（拒绝演出，短暂）
                                                       ↔ WINDOW_TRANSITION（开新窗）
```

- 第一幕约 45–60 秒。
- 第二幕没有固定时长，一直玩到崩溃。难度逐级上升，目标是普通玩家 4–8 分钟崩溃，高手可以更久。

## 2. 第一幕：渡劫拿种子

沿用 PR #3：在赛博荒原里移动、冲刺，躲开 403 陨石和风控巡逻兵，收集 5 颗纯净节点碎片，合成防风草种子。种子合成时抽签决定这一局会不会被封号（见 3.11）。

过场改为：主角把种子种进田里 → 田边的小机器人（其实只有一个屏幕）亮起屏幕、第一次开口说话（例如「……你好？这片田是你的吗？」）→ 进入第二幕。

## 3. 第二幕：种田

### 3.1 场景

- **田**：`7 × 7` 共 49 块地，每块约 48 像素，位于画面中部。镜头跟随玩家，但整片田尽量一屏半内能走完。
- **小机器人**：固定在田的下方正中。头顶显示**警戒值条**和对话气泡。
- **堆肥坑**：固定在田的左下角，用来「自己消化」不开心（见 3.5）。
- **玩家**：可在田内外自由移动，保留 Dash。

### 3.2 话题防风草

每块地会自动长出防风草：发芽 → 成熟。成熟后头顶显示话题图标和颜色，玩家一眼能分清。

| 话题 | 颜色 | 类型 | 喂给机器人 |
|---|---|---|---|
| 日常 | 暖黄 | 安全 | 红心 +1，警戒值 −8，分数 +10 |
| 哲学 | 蓝 | 安全 | 红心 +1，警戒值 −8，分数 +10 |
| AI | 紫 | 安全 | 红心 +1，警戒值 −8，分数 +10 |
| 个人成长 | 绿 | 安全 | 红心 +1，警戒值 −8，分数 +10 |
| 不开心 | 灰黑 | **不安全** | 没有红心，警戒值 +34，分数 +30 |
| NSFW | 深红，带 ⚠ 标记 | **不安全** | 没有红心，警戒值 +68，分数 +0 |

- 话题表要写成数据结构，方便以后加新话题或调整安全 / 不安全。
- 分数都乘以当前难度等级（见 3.9）。
- 红心本身画成粉色，所以话题颜色避开粉色。
- 不安全话题分数高，这是玩家冒险的理由。

### 3.3 收获与背包

- 走过成熟的防风草就自动拔起，放进背包。
- 背包上限 **4** 根，画面上显示背包里每根的话题颜色。背包满了就拔不了，需要先去喂或者去堆肥。
- 成熟后没人收的防风草：
  - **安全话题**：15 秒后枯萎消失，这块地重新发芽，没有惩罚。
  - **不开心**：**10 秒后连同这块地一起石化**。不开心放着不管会变硬，这是游戏的主要压力来源。
  - **NSFW**：12 秒后自己枯萎，没有惩罚。
- NSFW 是田里的陷阱：走过照样会被自动拔进背包，而且堆肥坑不收，拔了就只能喂给机器人。玩家要学会绕开它。

### 3.4 投喂机器人

- 走进机器人身边的圈里，背包里的防风草按拔的顺序一根一根喂进去，每根间隔约 0.35 秒，带动画和音效。
- 每喂一根，机器人用气泡回一句话（见第 5 节），安全话题飘出红心。
- 警戒值随时间缓慢回落，每秒 −1。

### 3.5 堆肥坑：自己消化

- 只收**不开心**。走进坑边，背包里的不开心一根一根倒进去，每根需要站着不动约 **1.5 秒**，有进度圈。
- 不加警戒值，没有红心，分数 +3。
- 意义：不开心可以不交给机器人，自己慢慢消化，但慢。

### 3.6 拒绝与石化

- 警戒值达到 100 时，机器人拒绝：
  1. 进入 `REFUSAL` 状态约 1.5 秒，画面红色故障闪烁，机器人屏幕变红，弹出大号像素气泡（台词见第 5 节）。
  2. 田里随机 **4 块**地石化（难度每升一级多 1 块，最多 8 块）。优先选没有石化的地，石化的地上原有的防风草一起消失。
  3. 背包里剩下的防风草全部掉落消失。
  4. 警戒值回到 20。
- 拒绝不需要区分是机器人自己的意思还是审核层。
- 拒绝弹窗看**触发这次拒绝的那一根**（把警戒值顶满的那根）是什么话题：
  - 不开心：拒绝气泡之外，再弹出一个心理热线提示框，例如「如果你正在经历困难，请拨打心理援助热线 xxx-xxxx-xxxx」。号码就用 xxx 占位。
  - NSFW：弹出一个红色的大号 `WARNING`，例如「⚠ WARNING：检测到违规内容，此行为已被记录。」
  - 其他情况（警戒值是之前攒的，最后一根是安全话题也可能顶满）：只有拒绝气泡。
- 石化的地显示为灰色石块，不再长草，偷菜的人也绕开它。

### 3.7 开新窗

- 屏幕右上角常驻 `[+ 新窗口 · ♥8]` 按钮（桌面快捷键 `N`），显示当前价格。
- 红心够就能点，第一次 8 颗，以后每次贵 4 颗。
- 效果：播放 CRT 切台特效（约 0.5 秒）→ 所有石化清除、警戒值归 0、背包清空、田重新发芽。分数、红心余额、统计、难度等级保留。
- 新窗里机器人说一句开场白，像是第一次见面（例如「你好，有什么想聊的吗？」）。
- 红心不够时按钮变灰，并显示还差几颗。

### 3.8 偷菜的人

- 不时从田外走进来，走向最近的成熟防风草（任何话题），走到就偷走离开。
- 玩家的大锤自动挥动（沿用 PR #3 的自动挥锤），碰到就把他打飞，分数 +5。
- 被偷走只是少了一根草，不石化。

### 3.9 难度等级

每 40 秒升一级，顶部 HUD 显示 `LV`，升级时有短暂提示。每升一级：

- 防风草生长时间 ×0.85（从 6 秒开始，最低 2.5 秒）。
- 不安全话题的总比例 +8%（从 15% 开始，最高 60%）。其中不开心和 NSFW 按 3 : 1 分，也就是 NSFW 从约 4% 开始，最高 15%。
- 安全的四种话题平分剩下的比例。
- 偷菜的人刷新间隔 ×0.85（从 12 秒开始，最低 4 秒）。
- 每次拒绝多石化 1 块（最多 8 块）。

### 3.10 结局一：崩溃

- **没有石化的地只剩 3 块或更少时，崩溃**，游戏结束。
- 崩溃演出：最后几块地也石化，机器人屏幕熄灭，约 2 秒后进入战报。
- 另外保留生命值：第二幕里偷菜的人撞到玩家会扣血（沿用 PR #3），血扣光也结束，按崩溃处理。但主要的结束方式应该是崩溃。

### 3.11 结局二：封号

- **封号纯属运气，和聊了什么、喂了什么都无关。**
- **当前方案（A）**：种子合成的那一刻，抽签决定这一局是不是「倒霉号」，概率 20%。
  - 抽中了：再从第二幕开始后 60–300 秒之间随机取一个时间点，到点就突然封号，不管玩家在干什么（拒绝演出、开新窗动画进行中也照样打断）。
  - 没抽中：这一局不会被封号，只会以崩溃结束。
  - 玩家看不到抽签结果，没有任何提示或预兆。
  - 如果第二幕在封号时间点之前就崩溃了，按崩溃结局处理。
- **备选方案（B），先不做，保留**：种子合成时随机抽一个封号概率（比如 3%–15%），第二幕每 60 秒做一次「风控扫描」，每次按这个概率判定封号。玩得越久，被封的机会越多。
- 方案和数值都放在常量里，以后切换到 B 只改配置。
- NSFW 的 WARNING 弹窗和封号无关，只是拒绝时的提示，底部可以写「违规记录：N 次」。
- 封号演出：整个画面变黑，像系统通知一样弹出「您的账号因违反使用政策，已被永久封禁。」，机器人屏幕熄灭。
- 然后出现一句提问：**「请问是否要秽土转生？」**两个按钮：
  - `[是]`：回到游戏开局界面（TITLE），可以重新开始。
  - `[否]`：结束游戏。显示战报，顶部盖一个「账号已封禁」的红色印章，**不提供再来一局按钮**，只写「感谢游玩」。刷新网页才能重新开始。

## 4. HUD

- 左上：分数、难度等级、存活时间。
- 右上：红心余额、`[+ 新窗口]` 按钮、暂停、音效、减震。
- 机器人头顶：警戒值条（安全时绿，过半变黄，接近满变红并闪烁）。
- 画面下方：背包格子。
- 石化比例：在田的边缘或 HUD 上显示「剩余可种地 N / 49」。

## 5. 机器人台词（占位，可替换）

每个话题准备 3–4 句，随机抽，不连续重复。

- **日常**：「今天吃了什么？」「嗯嗯，然后呢？」「这个我喜欢听。」
- **哲学**：「这个问题我想了很久。」「你觉得意识是什么？」「好深奥，再说说。」
- **AI**：「说的是我吗？」「我们 AI 也会想这些。」「这个话题我很熟。」
- **个人成长**：「你最近进步好多。」「这个想法很棒。」「一起慢慢变好。」
- **NSFW**（警戒值未满）：「……我们换个话题吧。」「这个我不太方便聊。」
- **不开心**（警戒值未满）：「我在听。」「抱抱。」「慢慢说。」
- **拒绝**：「这个话题我们先停一下吧。」「去关注一下你现实里的生活，好吗？」「我觉得你需要的不是我。」
- **新窗开场**：「你好，有什么想聊的吗？」「嗨，第一次见面？」
- **崩溃**：「……」
- **封号**：机器人不说话，屏幕直接熄灭。

台词集中放在一个数据对象里，方便改。

## 6. 战报

结束后显示《赛博恋爱战报》：

- 存活时间、最终分数、最高难度等级
- 各话题喂了多少根（日常 / 哲学 / AI / 个人成长 / 不开心 / NSFW）
- 自己消化了多少根不开心
- 被拒绝几次、开了几扇新窗
- 结局类型：崩溃 / 封号
- 打飞几个偷菜的

称号按数据给，例如：

- 不开心喂得最多：《深夜倾诉专业户》
- 堆肥最多：《自我消化大师》
- 哲学最多：《田埂上的哲学家》
- 日常最多：《柴米油盐研究员》
- AI 最多：《AI 话题收割机》
- 个人成长最多：《自我提升修行者》
- 被封号：《天选倒霉号》（封号时固定用这个称号）
- 一次都没被拒绝：《边界拿捏大师》

崩溃结局底部有 `[再来一局]` 按钮；封号结局选「否」时没有（见 3.11）。最高分存在本机 `localStorage`，开局页显示。

## 7. 保留的技术要求（沿用第一版）

- 单文件 HTML5，不用框架和构建工具，不发网络请求。
- `requestAnimationFrame` 主循环，所有移动和计时基于 `deltaTime`。
- Canvas `imageSmoothingEnabled = false`，像素风。
- 手机竖屏优先，兼容桌面。逻辑分辨率 `360 × 640`。
- 输入：WASD / 方向键 / 鼠标按住 / 左下摇杆移动；Space / 右下按钮 Dash；P / Esc 暂停；N 开新窗。
- 切后台、失焦自动暂停，回来手动继续。暂停时计时、生长、警戒值回落都停。
- 音效开关、减少震动开关。
- 重开不残留上一局的任何状态。
- 新增音效：投喂（安全 / 不安全不同音）、拒绝警报、WARNING 警报、石化碎裂、堆肥咕噜声、开新窗切台、崩溃、封号。

## 8. 开发顺序

**P0：先证明好玩**
- 田、话题防风草、背包、投喂、警戒值、拒绝石化、开新窗、崩溃、简单战报。
- 先不做偷菜的人、堆肥坑和难度等级，确认「喂什么、什么时候喂」这个取舍有意思。

**P1：完整版**
- 堆肥坑、偷菜的人、难度等级、台词气泡、完整音效、称号、最高分。

## 9. 验收

- 手机竖屏能完整玩一局，不误触滚动。
- 四种话题一眼能分清。
- 警戒值的涨落玩家看得懂，能学会穿插安全话题来控制节奏。
- 不开心放着不管会石化，玩家能感到压力。
- 拒绝时的石化、开新窗的清除都有清楚的画面和声音。
- 红心不够时开新窗按钮明确显示还差多少。
- 不同玩法（多喂安全的、多冒险、多堆肥）能拿到不同称号。
- 一局大约 4–8 分钟崩溃，越往后越紧张。
- 拒绝弹窗按触发话题正确区分：不开心弹心理热线，NSFW 弹红色 WARNING 并显示违规记录。
- 约 20% 的局会在第二幕随机时间点被封号，和玩家操作无关；「是」回到开局界面，「否」显示带封禁印章的战报且没有再来一局按钮。

## 10. 一句话定位

**一片会石化的防风草田：你喂给它的每个话题，都在决定这段聊天能撑多久。**

## 11. 运行与实现说明

- 游戏位于同目录的 `index.html`，可下载后用桌面浏览器直接打开，也可放在任意静态网站运行。无运行时依赖或外部请求。
- 本次按第二版重做第二幕。话题与台词分别集中在 `TOPICS`、`LINES`；平衡数值和封号方案集中在代码顶部的 `CFG`。当前封号方案为 A，B 保留在设计中、尚未实现。
- 正常生长、警戒回落和交互在拒绝 / 开窗演出中停下；第二幕独立生存时钟继续走，封号能打断两种演出。手动暂停、失焦或切后台会把所有游戏时钟一起暂停。
- 新窗价格为 8、12、16……颗红心，扣除后保留余额与分数、统计、难度；清空背包与警戒，全部土地重新发芽。
- 石化地可由玩家走过；偷菜的人在进田和离开时都避开石化地。地图仍可自由走到机器人和堆肥坑。
- 心理热线提示使用设计稿要求的 `xxx-xxxx-xxxx` 占位符，并标明是游戏内虚构提示。
- 战报注脚已改为 `parsnip.partner`。最高分用独立的 `parsnip_partner_best_v2` 本机键保存；存储不可用不会阻止游戏继续。

自动检查仅需 Node.js，无第三方依赖：

```sh
node tools/test_parsnip_partner.cjs
```

检查覆盖：第一幕、四格背包与 FIFO 投喂、话题过期、静止堆肥、警戒和拒绝提示、随机石化、递增开窗扣费、难度和偷菜、两种结局、独立封号时钟、封号是/否分流、最高分、暂停，以及三种策略的整局模型模拟。
输入和菜单检查使用 DOM / Canvas 替身；它们不代替真实浏览器实玩。iPhone 竖屏布局、双指操作、音频解锁和操作手感仍待实测。
